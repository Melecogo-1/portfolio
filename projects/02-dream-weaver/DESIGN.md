# 织梦者 · Dream Weaver —— 详细设计文档 v2

---

## 一、定位

数字卡牌叙事引擎。玩家以自由文本输入行动，系统用因果引擎推演后果，用预写的事件卡展示叙事。不需要AI，不需要网络，不需要GM。

## 三、核心数据结构

### 3.1 因果卡 (Causality Card)

```json
{
  "id": "tavern_favor",
  "name": "酒馆之恩",
  "type": "relation",        // relation | crime | knowledge | item
  "description": "你帮老汤姆修好了酒桶。他欠你一个人情。",
  "effects": {
    "npc_attitude": {"tavern_owner": 20},
    "dialogue_unlock": ["老汤姆的秘密菜单"],
    "dice_bonus": {"charm": 5, "target": "tavern_owner"}
  },
  "story": "那天下午酒桶裂了一条缝，麦酒淌了一地。老汤姆急得团团转，你蹲下来用麻绳和松脂把裂缝堵上了。他没说谢谢——但他记住了。"
}
```

**因果卡类型：**
- `relation` — 和某个NPC的关系变化（好感/仇恨）
- `crime` — 犯罪行为留下的标记（会被守卫识别）
- `knowledge` — 获知的信息（解锁新对话选项）
- `item` — 获得的特殊物品（可在判定中消耗使用）

### 3.2 事件卡 (Event Card)

```json
{
  "id": "tavern_enter_001",
  "trigger": "enter_location:酒馆",
  "conditions": {
    "require_cards": [],
    "exclude_cards": [],
    "npc_alive": {"tavern_owner": true}
  },
  "versions": {
    "warm": {
      "condition": "player_has_card:tavern_favor",
      "text": "老汤姆从吧台后面抬起头，看到是你，咧嘴笑了一下。他从柜台下面摸出一个积灰的陶罐——'尝尝这个，去年埋的月光酒，从不给外人喝的。'",
      "outcome": "获得月光酒（物品），老汤姆好感+5"
    },
    "cold": {
      "condition": "player_has_card:blood_debt",
      "text": "门推开的一瞬，老汤姆的手已经在柜台下面握住了菜刀。他没有说话，但你从他的眼神里读到了——你最好别进来。",
      "outcome": "老汤姆态度：敌对。如果玩家继续靠近，触发战斗。"
    },
    "neutral": {
      "condition": "default",
      "text": "老汤姆抬头看了你一眼，手里擦杯子的动作没有停。'要什么？'他的语气不冷不热，是那种每天见过太多旅人的语气。",
      "outcome": "无特殊效果。可以点酒、问路、或者离开。"
    }
  }
}
```

**事件卡触发条件优先级：**
1. 检查玩家是否持有`require_cards`中的卡 → 有才触发
2. 检查玩家是否持有`exclude_cards`中的卡 → 有不触发
3. 检查NPC存活状态
4. 根据条件选版本：按warm/cold/neutral顺序检查condition → 第一个满足的生效

### 3.3 世界数据（保留现有结构，新增事件卡池）

```
世界JSON = {
  name, description, locations, npcs(保留现有关系网),
  event_cards: [100+张事件卡],
  causality_cards: [50张因果卡定义],
  player_identity: { name, backstory, starting_items }
}
```

## 四、游戏流程

### 4.1 开局

1. 玩家看到角色身份描述（五行，不可跳过但可忽略）
2. 获得初始因果卡（从身份设定中派生，例如"旧信"、"母亲的戒指"）
3. 站在村口，地图上四个地点可选

### 4.2 行动循环

```
玩家输入"我想XXX"
    ↓
系统解析行动类型（移动/对话/战斗/使用物品/观察）
    ↓
检查：玩家持有因果卡中，是否有直接触发的效果？
    ├── 有 → 跳过判定，直接触发对应事件卡版本
    └── 无 → 骰子判定
            ├── 成功 → 成功事件
            └── 失败 → 失败事件 + 可能获得负面因果卡
    ↓
展示事件卡文本
    ↓
如果是关键行动 → 发放新因果卡（翻转动画）
    ↓
更新世界状态（NPC态度/位置/存活）
    ↓
等待下一个输入
```

### 4.3 结局

当以下条件之一满足时触发结局：
- 玩家持有5张以上因果卡
- 某个关键NPC死亡
- 玩家主动选择"离开翡翠谷"
- 游戏时间达到2小时

系统根据玩家持有的因果卡组合，匹配对应的结局卡展示。

## 五、行动解析引擎

不依赖AI，用关键词匹配+上下文推断。

```
输入："我想和酒馆老板聊聊戒指的事"

解析结果：
  action_type: dialogue
  target_npc: tavern_owner
  topic: ring (匹配玩家物品"银戒指")
  intensity: normal

检查因果卡：
  - 玩家持有"旧信" → 老汤姆可能知道寄信人
  - 玩家未持有"血债血偿" → 不会触发敌对

骰子判定：
  基础成功率 = 魅力5 × 2 = 10
  因果卡加成 = 0
  → 掷D20，≤10成功
```

## 六、骰子系统

20面骰。动画：骰子在屏幕上滚动1.5秒，停在结果数字。

| 行动类型 | 判定属性 |
|---------|---------|
| 战斗/推撞 | 力量 |
| 潜行/盗窃 | 敏捷 |
| 解谜/观察 | 智力 |
| 说服/欺骗 | 魅力 |

公式：`成功率 = 属性值 × 2 + 因果卡加成 + 难度修正(-10~+10)`
掷D20 ≤ 成功率 → 成功。

---

## 七、事件卡三版本的判定逻辑

**不是"善/恶"二分。** 是根据因果引擎推演的**玩家与当前NPC/场景的关系状态**来选版本。

```
warm触发条件示例：
  - 玩家持有该NPC的正面关系因果卡
  - 该NPC的某个秘密被玩家获知但未泄露
  - 该NPC欠玩家人情

cold触发条件示例：
  - 玩家持有该NPC的负面关系因果卡
  - 该NPC的配偶/朋友因玩家行为受害
  - 该NPC在之前的互动中被玩家欺骗

neutral: 以上都不满足
```

这意味着同一个"走进酒馆"，面对老汤姆时可能有六种不同的响应——不只是warm/cold/neutral三版本，因为老汤姆的性格（豪爽但贪婪）和关系网（和马库斯是朋友，和玛莎是夫妻，和猎人有债务关系）会产生更细粒度的状态组合。

三版本是基础。关系网是变量。**同一个warm版本，如果上次玩家来的时候马库斯刚好也在——老汤姆的态度会更收敛，因为他在朋友面前不会表现得太热情。**

## 八、第一个预设世界：黑木村（Darkwood）

### 地点（4个）
- 🍺 老汤姆的酒馆
- 🏘️ 村口广场
- 🏔️ 北面森林
- 🏚️ 废弃矿洞

### NPC（4个）
- 老汤姆（酒馆老板）：豪爽但贪婪，和黑市有秘密交易
- 玛莎（老板娘）：胆小但精明，知道丈夫的秘密但装作不知
- 马库斯（守卫队长）：正直但固执，老汤姆的酒友
- 雷格（猎人）：沉默但重义，欠老汤姆三十枚银币

### 玩家身份（1个）

> 你是林隙。三个月前你收到一封旧信——母亲去世五年后，她的笔迹突然出现在你桌上。信上只有一句话："去黑木村，老汤姆的酒馆，找一个叫玛莎的女人。不要告诉任何人。"
>
> 你现在站在村口。风吹过北面的森林，带出一股说不清的甜腻气味。你身上有三枚银币、一封旧信、和母亲留给你的银戒指。
